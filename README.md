## 🚀 Tech Stack

- **Framework**: React 19
- **Bundler / Dev Server**: Vite 8
- **Styling**: Tailwind CSS with custom glassmorphism and animations
- **Icons**: Lucide React + custom SVG brand icons
- **Effects**: Canvas Confetti
- **Deployment Target**: Vercel (Configured with `vercel.json` SPA rewrites & asset caching)

---

## 🛠️ Local Development

### 1. Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
Production build assets will be generated in `dist/`.

### 5. Preview Production Build
```bash
npm run preview
```

---

## 🚢 Deploy to Vercel

### Option 1: Vercel CLI
```bash
npx vercel
```

### Option 2: GitHub Integration
1. Push this repository to your GitHub account (`https://github.com/gaurangsoni/my-portfolio`).
2. Log into [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository.
4. Vercel automatically detects **Vite** and configures:
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. Click **Deploy**!
